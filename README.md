## v3.9.2 (2026-11-18) — 전수 클릭 QA에서 잡은 6건 수정

전 모드를 실제 브라우저에서 하나씩 클릭해 점검(360·390px, 344건)하고 발견한 것을 고쳤다.

1. **「10문제 더 풀기」가 다른 학습을 시작하던 문제** — 단계 시트에서 Lv.4를 골라 학습한 뒤 결과 화면의 「10문제 더 풀기」를 누르면 **프리셋(Lv.4·5·3) 세트**가 나왔다(단계가 사라짐). 이제 세션에 단계(`stageLv`)를 남겨 **같은 단계**로 이어간다. 새 카드·오답 집중도 각각 그 모드로 이어진다. 중도에 나갔다 「이어서 풀기」로 돌아와도 단계·회화 모드가 유지된다.
2. **말하기 10문제를 마치면 막다른 화면** — 완료 후에는 「10문제 더」 버튼도, 다시 시작할 길도 없었고, 늦게 도착한 음성인식 결과가 `speakCheck`에서 예외(`Cannot read properties of undefined`)를 던졌다. 완료 화면을 **점수 요약 카드 + 「10문제 더」**로 바꾸고(다음 세트는 안 해 본 문장부터), 빈 세트·마이크·건너뛰기에 가드를 넣었다.
3. **플래시카드 앞면 🔊 가 예문을 읽던 문제** — 카드 앞면(단어 + 발음기호)의 발음 버튼이 단어가 아니라 예문을 읽었다. 이제 앞면은 **단어**(회화 카드는 문장)를 읽고, 예문은 뒤집은 뒤 「🔊 예문」 버튼으로 듣는다.
4. **오답 집중이 오늘 틀린 카드를 맨 뒤로 밀던 문제** — 정렬이 「오늘 푼 카드 뒤로」라, 오답이 10개를 넘으면 방금 틀린 카드는 세트에 들지 못했다. 이제 **10분이 지나 다시 물어볼 때가 된 오답을 맨 앞**(오래된 순)에 놓고, 그다음 오답 횟수 순으로 놓는다 — 10분 전에는 재출제되지 않고 10분 뒤에는 먼저 나온다.
5. **AI 회화방 응답 대기 중 나가면 예외** — LLM 응답을 기다리는 사이 대화방을 닫으면 늦게 온 응답이 `chatTopic`(null)을 읽다 unhandled rejection을 던졌다. 요청 시점의 주제를 붙잡아 저장·표시가 정상 동작한다.
6. **단어장 한글 검색이 예문 해석을 못 찾던 문제** — 검색이 뜻(`m`)만 봐서, placeholder 예시인 「퇴근」처럼 **예문 해석에만 있는 말**은 0건이었다. 예문 해석(`k`)까지 검색한다(「퇴근」 12건). 「4지선다로 대쳴」 오타도 「대체」로 고쳤다.

검증: `qa2.html`(신규) — 실제 클릭 344건, 360·390px 폭/글자쪼개짐/겹침·콘솔에러 0건. 상세는 `verify-v3.9.2.md`.

## v3.9.1 (2026-11-18) — 「같은 문제만 계속 나오는」 반복 출제 버그 수정

1. **원인** — 세트 짜기가 학습 이력을 보지 않고 잘라 쓰고 있었다. ①「오늘 복습할 카드」는 오늘 몫의 복습·새 카드가 떨어지면 **오답 노트(틀린 적 있는 카드)로 채우는 폴백**으로 넘어갔고, ②「실전 회화·구문 드릴·말하기」는 수록 순서(중요도) **상위 10개를 매번 그대로** 잘랐다. SRS 갱신 자체(정답 시 due +1일)는 정상이었고, 세션도 완료 시 비워지고 있었다.
2. **공통 세트 짜기 `makeSet()`** — 우선순위를 하나로 통일: ① 복습 대기(due ≤ 지금, 오래된 순) → ② 한 번도 안 푼 카드(중요도 순) → ③ 오래 전에 본 카드(가장 오래된 순 = 2회차 순환) → ④ 오늘 이미 푼 카드(먼저 푼 순, 맨 마지막). 한 세트 안 중복 없음.
3. **적용 범위** — 「오늘 복습할 카드」·「새 카드」·「오답 집중」·실전 회화·구문 드릴·말하기·단계(Lv) 시트 학습이 모두 같은 함수를 쓴다. 오답 카드는 10분 뒤 도래했을 때만 재출제된다. 말하기는 따라 말한 카드에 `sp`(마지막 말하기 시각)를 남겨 다음 세트에서 뒤로 밀린다.
4. **새 카드 한도** — 하루 몫(5/10/15개)을 다 쓴 뒤에도 세트가 계속 채워지므로 한도는 '최소 보장'이 된다(예전엔 한도 소진 후 같은 카드를 반복). 홈 문구도 「오늘 몫은 끝났어요 · 시작하면 안 본 카드가 이어집니다」로 수정.
5. **검증(qa=1)** — 라이브에서 「오늘 복습할 카드」10→10 겹침 0건, 「실전 회화」10→10 겹침 0건, 콘솔 에러 0건. 학습 이력(복습 대기 10 + 오답 10 + 예전 카드 10) 시드 테스트에서도 1세트=복습 대기 10장 정확히, 이후 겹침 0건.

## v3.9 (2026-11-18) — 글자·레이아웃 깨짐 수정 + 회화 중요도 순 배치

1. **홈 도구 카드가 세로로 찢어지던 문제** — 「🗣️ 말하기·발음 교정」 카드가 34px 폭으로 찌그러져 글자가 한 자씩 세로로 쌓이고 옆 카드와 겹쳤다. 원인은 학습 화면의 원형 듣기 버튼 클래스 `.speak`(34×34, `margin-left:auto`)가 같은 이름의 `tool-card speak`에 함께 걸린 것. 도구 카드는 `t-speak` / `t-chat`으로 분리하고, 2열 그리드를 `repeat(2, minmax(0,1fr))`로 바꿔 어느 폭에서도 반씩 나뉘게 했다.
2. **글꼴·줄바꿈 보강** — 본문 글꼴 스택에 Noto Sans KR·SamsungOne·컬러 이모지 폰트를 넣고 `word-break: keep-all`(한글 단어 중간 끊김 방지) + `overflow-wrap: anywhere`(긴 영어만 끊김)를 적용. 발음기호(IPA)는 전용 스택으로 분리해 네모(□)로 깨지지 않게 했다.
3. **회화 중요도(빈도) 순 배치** — 카드마다 중요도 순위 `f`와 배지 등급 `ib`(2=필수★, 1=고빈도)를 빌드에서 계산해 **단계 안 배열 자체를 중요도 순으로 정렬**했다. 근거: NGSL-Spoken(실제 구어 721) 순위 + OpenSubtitles 자막 빈도 + CEFR 위치, 기능어(관사·전치사·대명사·조동사·접속사·감탄사)와 상투적 부사(out·up·just·so 등)는 빈도가 높아도 뒤로. Lv.5 청크는 구성 단어 빈도 + 태그 가중, Lv.6 통문장은 상황 가중(일상·카페·직장 먼저) + 문장 단어 빈도.
4. **출제도 중요도 순** — 새 카드는 단계 배열 앞에서부터, 구문 드릴·실전 회화·말하기도 같은 순서. 설정에 「출제 순서: 중요도 순(기본) / 랜덤」을 추가해 예전처럼 섞을 수도 있다. Lv.3 상위 15% 프리셋의 `hard` 필터가 반대로 걸려 **덜 중요한 60%**를 뽑고 있던 버그도 고쳤다.
5. **목록·상세에 중요도 배지** — 단어장 행과 카드 상세에 `필수★` / `고빈도` 배지를 붙이고, 단어장 머리에 「중요도 순」 표시. 홈 시작 문구에도 현재 순서를 적는다.

## 2. 학습 방식

1. **난이도 프리셋** — 홈 상단에서 원탭.
   - 중급: Lv.3 55% · Lv.4 45%
   - 중상급(기본): Lv.4 60% · Lv.5 25% · Lv.3 상위 15%
   - 구문·패턴: Lv.5 100%
   - 설정에서 "초급 Lv.1·2 포함"을 켜면 Lv.1·2가 더해진다.
2. **4지선다** — 단어→뜻 / 뜻→단어. 오답이면 고른 보기의 뜻을 함께 보여준다.
3. **빈칸 채우기(말해보카식)** — 회화 예문의 핵심 표현을 `____`로 뚫고 4개 중 고른다.
   정답 뒤에 **"왜 이 표현인가"** — 같은 동사의 다른 입자(off/out), 같은 태그의 다른 표현, 고른 보기의 뜻을 비교한다.
4. **문장 순서 맞추기(듀올링고식)** — 한국어를 보고 영어 타일을 순서대로 탭. 놓은 타일을 다시 탭하면 빠진다.
   힌트는 다음 타일을 3회까지 알려주고, 첫 오답에는 재시도 1회, 두 번째 오답에 정답·어순 설명을 보여준다.
5. **구문 집중 드릴** — 홈의 「💬 회화 구문·문장 훈련」 카드에서 태그(구동사/회화 구문/연결·논리/의견·감정/부탁·제안/화법·완곡/사과·문제/비즈니스…)를 고르고 빈칸·순서·뜻 맞히기로 몰아서 25장.
6. **SRS 사다리** — 오답 10분 → 1 → 3 → 7 → 14 → 30일 → 마스터(60일+). 오답은 세션 내 3~4문제 뒤 재등장.
7. **실전 회화 문장(Lv.6)** — 상황 태그(카페·식당 … 교통·길찾기 13종)를 고르고 25문장씩.
   각 카드는 **문장 + 자연스러운 한국어 + 원어민 응답(↳) + 응답 뜻 + 빈칸 표현·뜻 + 핵심 포인트**.
   · 빈칸: 문장 자체에서 핵심 표현(`b`)을 뚫고, 같은 상황의 다른 표현 3개와 비교
   · 순서: 한국어 뜻을 보고 문장 타일 조립(최대 13타일)
   · 뜻 맞히기: 한국어 → 영어 문장(기본 방향)
   · 카드: 앞면 한국어 / 뒷면 영어 문장 + 응답 + 핵심 포인트(말하기 방향)
8. **학습 모드별 기록·진도** — 모드마다 오늘 학습 수·정답률·누적 수를 따로 쌓고, 홈 「오늘 학습 기록」과 통계 「학습 모드별 기록」 표에 표시.
   단계별로는 **학습 진도(본 카드)** 와 **마스터율**을 2중 바로 보여준다.
9. **듣기 속도** — `🔊 1.0x` / `🐢 0.75x` 토글(학습 화면 상단·설정). 발음은 브라우저 음성 합성(en-US).
10. **단어장·통계** — 레벨·북마크·오답·복습 대기 필터, 검색, 마스터율, 7일 학습량, 연속 학습일, JSON 백업.
11. **수록 기준 화면** — 단계 표 + 어휘 사다리 + CEFR 분포 + 표준 목록 수록률 + 참고한 단어장·채널·앱.

## 5. 카드 필드

표제어, 품사, IPA, 한국어 뜻 1~2개, 실전 회화 예문 + 해석, 레벨. Lv.5는 `t`(태그: 구동사/회화 구문/연결·논리/…).
Lv.6은 `t`(상황 태그), `e`/`k`(원어민 응답 + 뜻), `b`/`bm`(빈칸 표현 + 뜻), `x`(핵심 포인트)를 함께 가진다.
원본은 `data/curated_lv6_conv1~4.tsv` — `문장|유형|한국어 뜻|응답(영어)|응답(한국어)|상황 태그|빈칸 표현|빈칸 뜻|핵심 포인트`(9열).
빌드가 **빈칸 표현이 문장 안에 실제로 있는지**와 중복을 검사한다.
